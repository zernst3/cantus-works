What actually happened

The AI was never the problem.

We learned this on our own projects. An agent kept making database calls in the service layer, despite the separation we had set up in example endpoints. The examples were not good enough for enforcement. So we wrote a hard rule, database calls live only in the repository layer, and wired a machine to enforce it. It never made the mistake again.

That is the whole practice. We find where a codebase has drifted from its own rules, we fix what the drift broke and we write the rules down with machines to enforce them, so it does not happen again after we leave.

Every codebase drifts from its own rules. We hold the line.
